title: Playlists description: Tabs, adding files and folders, removing, selecting, sorting, filtering, moving tracks, exporting M3U and where Nastro stores your playlists. ---

Playlists

Nastro keeps any number of playlists, one per tab. They are saved as you work and come back the next time you start the player.

Tabs

The tabs are at the top of the playlist panel. Click a tab to show that playlist. The first time you run Nastro there is one empty playlist, named Playlist 1.

  • New playlist: the + button next to the tabs, or File, New playlist (Ctrl N). It is added after the others, shown, and named Playlist followed by a number.
  • Rename: double click the tab, or File, Rename playlist, which also shows the playlist panel if it was hidden. Type the new name and press Enter. Clicking away cancels, and an empty name is ignored.
  • Close: File, Close playlist closes the playlist shown and deletes its file, without asking. The last remaining playlist is not closed, it is emptied.

Each tab has its own selection and its own filter. The playlist that holds the loaded track is the one Next, Previous and the end of a track follow, even when you are looking at another tab.

Adding tracks

Three ways, all of which add to the end of the playlist shown:

  • The menus. File, Open files... (Ctrl O or L, and the open button of the player) adds the files you choose and starts playing the first one added. File, Add files... and Add folder... (Ctrl Shift O) add without playing. The ADD button of the playlist offers the same two. You can choose several files or folders in one go.
  • Drag and drop. Drop files, folders or playlist files on the Nastro window. They are added without playing.
  • The command line. See Playback.

What is added:

  • A file in a supported format becomes one track. Single files keep the order in which they were given. Files of any other kind are skipped silently.
  • A folder adds every supported file inside it, including all its subfolders (up to 16 levels deep), sorted by path. Hidden files and folders, those whose name starts with a dot, are skipped, and so are playlist files found inside the folder.
  • A playlist file (.m3u or .m3u8) that you choose or drop directly adds its entries in order. Relative paths in it are read from the folder of the playlist file.

The tracks appear at once and Nastro fills in titles, artists and lengths in the background, so adding a large folder never freezes the window. A track shows Artist - Title, or the title alone, or the file name without extension when it has no title tag, and its length on the right. The track that is loaded is marked with a play glyph in place of its number. The footer shows the number of tracks and their total length, for example 12 tracks · 0:48:05.

Selecting

The SELECT button has three commands: Select all (Ctrl A), Select none and Invert selection. These work on the whole playlist, including tracks the filter is hiding.

Removing tracks

The REMOVE button has three commands:

  • Remove selected (Delete): removes the selected tracks.
  • Keep only selected: removes every track that is not selected.
  • Remove all: empties the playlist.

Removing tracks from a playlist never touches the files on disk.

Sorting

The SORT button reorders the whole playlist:

CommandOrder
By titleA to Z by title tag.
By artistA to Z by artist tag.
By albumA to Z by album tag.
By file nameA to Z by file name.
By pathA to Z by the full path.
By lengthShortest first.
ReverseThe current order, backwards.
RandomizeA new random order every time. This changes the playlist itself, it is not the same as shuffle.

Text is compared ignoring case and accents. Tracks that lack the value (no artist tag, say) go to the end. Sorting keeps the selection and the loaded track on the same tracks.

Moving tracks

Select one or more tracks, click the track list so it has the focus, and press Alt ↑ or Alt ↓ (Option on macOS) to move them one position up or down. Several selected tracks move together and keep the distance between them, and they stop at the top or the bottom of the playlist.

Filter

The Filter box at the right of the tabs narrows the list as you type. Ctrl F (⌘ F) puts the cursor in it.

  • It looks at the track line (artist and title) and at the file name.
  • It ignores case and accents: dvorak finds Dvořák.
  • Words are separated by spaces and every word must match, anywhere and in any order: satie gym finds Erik Satie - Gymnopédie No. 1.

When nothing matches, the list says No tracks match this filter. Each playlist keeps its own filter text. The filter only hides tracks: it does not remove anything and it does not change the play order. While you type in the box, the single-key shortcuts are off, see Keyboard shortcuts.

Exporting a playlist

File, Export playlist... saves a copy of the playlist shown as an extended M3U file in UTF-8, so other players can open it. The save dialog starts in your Music folder (or your home folder) with the playlist name and the extension .m3u8 as the suggested file name. The tracks are written with their full paths, so the exported file works from any folder on the same computer. Exporting does not change the playlist.

Where playlists are stored

Every playlist is saved automatically, a couple of seconds after the last change and again when you quit, as a plain file in the playlists folder, named playlist-1.m3u8, playlist-2.m3u8 and so on. The name you gave it is stored inside the file. The order of the tabs, the tab you were on and the loaded track are remembered in the session file. The folder is listed in Files and folders.

Playlists store the path of each file. If you move or rename a music file, its track stays in the playlist and is skipped when played, see Errors and skipped tracks. Closing a tab deletes its file.
