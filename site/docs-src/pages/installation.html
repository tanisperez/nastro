Installation

Nastro is a single desktop application with no account and no sign in. Download it for your system, or build it from source.

Early development

There is no release yet. The download links and package repositories below describe how releases will be published, and the website and repository addresses are provisional. Linux comes first; Windows and macOS builds are not verified yet.

Linux

Debian and Ubuntu (apt)

Add the signing key and the repository once, then install. Your usual apt upgrade keeps Nastro up to date.

```shell $ sudo curl -fsSLo /etc/apt/keyrings/nastro.asc https://nastro.tanis.codes/nastro.asc $ echo "deb [signed-by=/etc/apt/keyrings/nastro.asc] https://nastro.tanis.codes/apt stable main" \ | sudo tee /etc/apt/sources.list.d/nastro.list $ sudo apt update && sudo apt install nastro ```

Fedora and openSUSE (dnf, zypper)

Add the repository once, then install. The signing key is imported on the first install.

```shell # Fedora $ sudo curl -fsSLo /etc/yum.repos.d/nastro.repo https://nastro.tanis.codes/rpm/nastro.repo $ sudo dnf install nastro # openSUSE $ sudo zypper addrepo https://nastro.tanis.codes/rpm/nastro.repo $ sudo zypper install nastro ```

Tarball

The .tar.gz uses a /usr-like layout: bin/nastro, plus the desktop entry and the icons under share/. Extract it anywhere and run bin/nastro, or copy its contents under ~/.local to get the menu entry. You also need the ALSA runtime library (libasound2 on Debian and Ubuntu, alsa-lib on Fedora). A tarball install does not update itself: download new versions from the releases page.

What the Linux packages install

The .deb and .rpm packages install /usr/bin/nastro, a desktop entry and the icons. The desktop entry lists the common audio types and M3U playlists, so Nastro shows up in the "Open with" menu of your file manager.

Windows

Download Nastro-…-windows-x86_64-setup.exe and run it. The installer is per user: it installs into %LOCALAPPDATA%\Programs\Nastro, needs no administrator rights and adds a Start menu shortcut (and an optional desktop shortcut). One unchecked option makes Nastro an "Open with" choice for audio files and playlists.

Portable zip

On a machine where running an installer is not allowed, download Nastro-…-windows-x86_64-portable.zip instead. It holds nastro.exe, the license and the notice. Unzip it anywhere you can run programs from and double click nastro.exe. There is nothing to install: no shortcut, no file association and no entry in Apps. To remove it, delete the folder. A portable copy still keeps its settings and logs in your user folders, see Files and folders.

macOS

Download Nastro-…-macos-arm64.dmg, open it and drag Nastro to Applications.

First launch of an unsigned build

Nastro is not code signed yet, so your system asks once before opening it.

  • macOS: if macOS says it cannot verify the developer, open System Settings, Privacy and Security, and choose Open Anyway. Or run this once: ```shell $ xattr -dr com.apple.quarantine /Applications/Nastro.app ```
  • Windows: if SmartScreen shows Windows protected your PC, choose More info and then Run anyway.

Updates

Nastro has no built-in updater and never contacts the network on its own.

Uninstall

  • Debian and Ubuntu: sudo apt remove nastro, then delete /etc/apt/sources.list.d/nastro.list and /etc/apt/keyrings/nastro.asc if you no longer want the repository.
  • Fedora: sudo dnf remove nastro and delete /etc/yum.repos.d/nastro.repo.
  • Windows: Settings, Apps, Nastro, Uninstall. A portable copy is not listed there: delete its folder.
  • macOS: drag Nastro from Applications to the Trash.

Uninstalling never touches your music or your playlists. To remove your settings, playlists, skins and logs as well, delete the folders listed in Files and folders.

Build from source

Nastro builds with the stable Rust toolchain. Install Rust with rustup; the exact toolchain version is pinned in rust-toolchain.toml and installed on the first build. Then install the system dependencies:

  • Linux (Debian and Ubuntu package names; on Fedora install alsa-lib-devel for the audio library): ```shell $ sudo apt install build-essential pkg-config cmake libfontconfig-dev libfreetype-dev \ libwayland-dev wayland-protocols libxkbcommon-dev libxkbcommon-x11-dev \ libx11-xcb-dev libxcb1-dev libvulkan-dev libasound2-dev ```
  • macOS: Xcode with its command line tools.
  • Windows: the Visual Studio Build Tools with the "Desktop development with C++" workload.

Then build and run:

```shell $ git clone https://github.com/tanisperez/nastro.git $ cd nastro $ cargo run $ cargo build --release ```

The first command builds and starts a debug binary. The second builds an optimized binary in target/release/nastro. A full build of gpui takes a while and several GB of disk space.
