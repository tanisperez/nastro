Keyboard shortcuts

Nastro can be played entirely from the keyboard. On macOS, use ⌘ wherever Linux and Windows use Ctrl, and Option wherever they use Alt.

Single keys and text fields

The single-key shortcuts (Z X C V B, Space, the arrows, S, R, L, T, Delete, Enter and select all) only work while no text field has the focus. While you type in the playlist Filter box or rename a playlist, those keys just edit the text. Click anywhere outside the field, or press Enter when renaming, to get them back. Shortcuts that include Ctrl (⌘), Alt or F1 work everywhere.

Shortcuts in menus

The menus show the shortcut next to the commands that have one. Everything else in Nastro is done with the mouse: the equalizer sliders, the seek bar, the volume and balance sliders and the presets menu have no keyboard shortcuts.
