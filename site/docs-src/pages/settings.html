title: Settings description: Every Nastro setting: language, menu theme, skin, skin size, clock, visualizer and log level, where to change each one, its default, and the settings.toml keys and values. ---

Settings

Open Preferences with File, Preferences... (or Options, Preferences...) or Ctrl P (⌘ , on macOS). Changes apply immediately and are saved as you make them: there is no Save button. The bottom of the window says where the file is.

Preferences is a window of its own, with one row of choices for each setting. Click a choice to select it, the selected one is highlighted. The settings are listed here in the order the window shows them. Things that change while you listen, such as the volume, the equalizer or where the panels are, are not settings, Nastro remembers them in the session file.

Language

Automatic follows your system: Nastro uses the first of your system languages that it has, and English if it has none. Written next to it is the language that was detected, for example Automatic (Español). The other choices are shown in their own language: English, Español, Galego and Italiano. The change is immediate, with no restart. Variants such as es-MX or it-CH use their base language. Not everything is translated: log messages, codec names and units (FLAC, kbps, kHz) and keyboard shortcut names stay as they are.

Menus and windows

Whether the menus, Preferences and About are light or dark: System follows the light or dark setting of your computer, Light and Dark force one. As the hint in the window says, the skin keeps its own colors: this does not change the player, the equalizer or the playlist.

Skin

The list shows every skin: Silver, Graphite, Porcelain and Nebula, followed by the ones you installed. A hint under it gives the folder for your own skins. After you copy a new skin there, use Options, Skin, Reload skins to read the folder again, and Open skins folder to open it. If the skin you chose is gone the next time Nastro starts, it falls back to Silver. See Skins.

Skin size

1x, 1.5x or 2x: how big the panels are drawn, whatever the scale of your screen. Use a bigger size on a high resolution screen or if you find the controls too small. The menus and Preferences are not affected. Panel positions and the playlist size scale with it.

Clock

Elapsed time shows how long the track has been playing. Remaining time shows how long is left, with a minus sign. You can also switch by clicking the clock in the player.

Visualizer

Spectrum, Oscilloscope or Off. You can also click the visualizer in the player to go through them.

Log level

How much Nastro writes to its log file. The hint under the choices gives the path of the file.

ChoiceWhat is logged
OffNothing.
ErrorsOnly errors.
WarningsErrors and warnings.
Information (default)Startup, the tracks played and settings changes, plus warnings and errors.
DebugAlso the state changes that help to diagnose a problem.
TraceEverything, including every screen redraw. Very verbose, only for bug reports.

The change applies at once. The NASTRO_LOG environment variable overrides this choice for one run, see Troubleshooting.

The settings.toml file

The settings are stored in settings.toml, in the configuration folder listed under Files and folders. It is a plain text file. Nastro reads it only when it starts and rewrites it, with every key, each time you change a setting, so edit it while Nastro is closed.

```toml title="settings.toml" language = "auto" theme = "system" skin = "silver" skin_scale = 1.0 time_display = "elapsed" visualizer = "spectrum" log_level = "info" ```
KeyValuesDefault
language"auto", "en", "es", "gl", "it""auto"
theme"system", "light", "dark""system"
skinA skin id: "silver", "graphite", "porcelain", "nebula", or the id of one of your skins (its file or folder name). An unknown id falls back to Silver."silver"
skin_scale1.0, 1.5 or 2.0 (a number, not text; 1 and 2 also work)1.0
time_display"elapsed", "remaining""elapsed"
visualizer"spectrum", "oscilloscope", "off""spectrum"
log_level"off", "error", "warn" (or "warning"), "info", "debug", "trace""info"

Text values are not case sensitive, except skin ids. Every key is read on its own: a missing key, a wrong type or a value that does not exist falls back to the default of that key only, and keys Nastro does not know are ignored. A file that is not valid TOML at all gives all the defaults. To go back to the defaults, delete the file while Nastro is closed.
