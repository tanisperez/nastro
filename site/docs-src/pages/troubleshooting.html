Troubleshooting

Most problems are one of two kinds: the sound goes to the wrong place, or Nastro cannot read a file. The log says which.

No sound

Nastro plays through your system's default audio output. If a track is playing, the clock is moving and you hear nothing:

  1. Check the default output device. In your system sound settings, make sure the default output is the speakers or headphones you expect, and that it is not muted. Nastro follows the default device at the moment playback starts.
  2. Check the volume of Nastro itself and of the system mixer. Some mixers keep a separate volume for each application.
  3. On Linux, check the sound server. Nastro talks to ALSA. With PipeWire or PulseAudio, the ALSA plugin that routes it to the server must be installed: pipewire-alsa (or pipewire-audio) for PipeWire, pulseaudio-alsa (the alsa-plugins package on some distributions) for PulseAudio. Without it, Nastro may open a raw hardware device that another program is already using.
  4. Check that something else is not holding the device. With plain ALSA, only one program can use a card at a time.
  5. Look at the log, see below. A failure to open the output device is logged with the reason.

Quick test

Play any file with another program or run speaker-test -c 2. If that is silent too, the problem is in your system's audio setup, not in Nastro.

A file does not play

Nastro plays FLAC, MP3, Ogg Vorbis, WAV, AIFF and AAC in M4A files. A file that is truncated, protected by DRM or in another format is skipped, and the reason is written to the log.

The log

The log file is in the folder listed under Files and folders. On Linux:

```shell $ tail -f ~/.local/state/nastro/nastro.log ```

By default it records informational messages, warnings and errors. To see what Nastro is doing, start it with a more detailed level:

```shell $ NASTRO_LOG=debug nastro ```

NASTRO_LOG takes off, error, warn, info, debug or trace. It overrides the level for that run only.

Reporting a problem

Open an issue on GitHub with your system, how you installed Nastro and the relevant lines of a NASTRO_LOG=debug log. The log holds file paths, so look it over before posting it.
