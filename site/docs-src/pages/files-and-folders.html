title: Files and folders description: Every file Nastro reads and writes on your system: settings, session state, playlists, skins and logs. ---

Files and folders

Nastro never writes anything next to your music. Its own state lives in the standard folders of each system, and nothing is stored or sent anywhere else.

Your music

Nastro only reads your audio files. It does not move, rename, tag or copy them.

Configuration

Your settings and your skins.

SystemFolder
Linux~/.config/nastro/ ($XDG_CONFIG_HOME/nastro/)
macOS~/Library/Application Support/nastro/
Windows%APPDATA%\nastro\
PathContents
settings.tomlYour settings, see Settings. A plain TOML file you can read and edit while Nastro is closed.
skins/Your own skins, see Install a skin.

Session state

What Nastro restores at the next start: the volume and balance, shuffle and repeat, the equalizer, where the panels are and which are shown or collapsed, the list of playlists, the tab you were on and the loaded track. It is one file, session.toml, saved a moment after every change and again when you quit.

SystemFile
Linux~/.local/state/nastro/session.toml ($XDG_STATE_HOME/nastro/session.toml)
macOS~/Library/Application Support/nastro/session.toml
Windows%LOCALAPPDATA%\nastro\session.toml

Like the settings, each value is read on its own, so a damaged or older file never loses everything. Delete it while Nastro is closed to start from the default layout, volume and equalizer. Your playlists are not in it, only their file names, so deleting it leaves the playlist files in place, but Nastro forgets which ones were open.

Data

Your playlists.

SystemFolder
Linux~/.local/share/nastro/playlists/ ($XDG_DATA_HOME/nastro/playlists/)
macOS~/Library/Application Support/nastro/playlists/
Windows%APPDATA%\nastro\playlists\

Each playlist is one plain extended M3U file in UTF-8, named playlist-1.m3u8, playlist-2.m3u8 and so on, with the playlist name on a #PLAYLIST: line and the full path of each track. Other players and scripts can read them. Closing a playlist in Nastro deletes its file. See Playlists.

Logs

Nastro writes a log file, nastro.log. When it reaches 5 MB it is renamed nastro.1.log (the older ones move up to nastro.9.log), so at most 10 files are kept.

SystemFolder
Linux~/.local/state/nastro/nastro.log ($XDG_STATE_HOME/nastro/)
macOS~/Library/Logs/Nastro/
Windows%LOCALAPPDATA%\Nastro\logs\

The environment variable NASTRO_LOG sets the level at startup, see Troubleshooting.

Removing everything

Uninstalling Nastro leaves these folders alone. To remove all its traces, delete the configuration, data and log folders above. Your music is never in them.
