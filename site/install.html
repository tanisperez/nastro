Download Nastro

Free and open source. Early development: Linux comes first, and the Windows and macOS builds are not verified yet. Pick your system below, or install it with your package manager to get updates with the rest of your software.

  • Windows

    Windows 10 and 11, 64 bit. The installer is for your user only, needs no administrator rights. The portable zip needs no installer at all, for machines where installing is not allowed.

    Download the installer File Nastro-…-windows-x86_64-setup.exe Download the portable zip File Nastro-…-windows-x86_64-portable.zip

  • macOS

    Apple silicon (M1 and later). Drag Nastro to Applications.

    Download the disk image File Nastro-…-macos-arm64.dmg

  • Linux

    x86_64. A .deb, an .rpm and a tarball. Needs ALSA (libasound2, alsa-lib). Use a repository below to get updates.

    Download a package Files .deb, .rpm, .tar.gz
Package managers

Install from the command line

Each channel is updated with every release, so your usual upgrade command keeps Nastro up to date. Homebrew and winget are not set up yet.

Debian and Ubuntu apt

Add the signing key and the repository once, then install.

$ sudo curl -fsSLo /etc/apt/keyrings/nastro.asc https://nastro.tanis.codes/nastro.asc
$ echo "deb [signed-by=/etc/apt/keyrings/nastro.asc] https://nastro.tanis.codes/apt stable main" \
    | sudo tee /etc/apt/sources.list.d/nastro.list
$ sudo apt update && sudo apt install nastro

Fedora and openSUSE dnf, zypper

Add the repository once, then install. The key is imported on the first install.

# Fedora
$ sudo curl -fsSLo /etc/yum.repos.d/nastro.repo https://nastro.tanis.codes/rpm/nastro.repo
$ sudo dnf install nastro

# openSUSE
$ sudo zypper addrepo https://nastro.tanis.codes/rpm/nastro.repo
$ sudo zypper install nastro
First launch

A note on unsigned builds

Nastro is not code signed yet, so your system asks once before opening it.

macOS

If macOS says it cannot verify the developer, open System Settings, Privacy and Security, and choose Open Anyway. Or run this once:

$ xattr -dr com.apple.quarantine /Applications/Nastro.app

Windows

If SmartScreen shows Windows protected your PC, choose More info and then Run anyway.

Build from source

Nastro builds with the stable Rust toolchain. Clone the repository and run cargo run --release. See the README for the system libraries each platform needs (on Linux, including the ALSA development files).
